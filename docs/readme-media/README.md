# README media

These assets show the anonymous public BenchmarkWatcher app, captured on **3 October 2026**. They contain public historical observations, with no signed-in account, private research, browser chrome or credentials.

- `workspace.png`: commodity homepage, Table layout, 1Y observation window; capture after history previews render.
- `country-data.png`: country homepage filtered to consumer price inflation (`FP.CPI.TOTL.ZG`).
- `comparison.gif`: six captured UI states at `/commodity/gold`: select 1Y, open Compare, add Silver, add Copper, close the picker, inspect a dated tooltip. This is a short step-by-step walkthrough, not a live data feed.

PNG captures use a 1440 × 920 viewport. The GIF is scaled to 1080px wide with a limited palette to keep GitHub's README lightweight. Capture the actual UI again when these journeys change; do not mock values or edit observations into screenshots. Use an anonymous browser context and inspect images for personal information before publishing.

The README logo reuses `app/static/images/brand-icon-512.png`. Its canonical artwork remains unchanged. Native platform icon exports are separate assets.
